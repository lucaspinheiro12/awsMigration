1. Amazon EC2 (Elastic Compute Cloud)
Uso Sugerido: Hospedagem de sistemas ERP, sistemas de controle de estoque e plataformas internas.

Vantagens:

Pague apenas pelo tempo de uso ("Pay-as-you-go").

Permite desligar instâncias fora do horário comercial para economizar.

Possibilidade de usar instâncias reservadas (até 72% de economia).

Escalabilidade automática em períodos de alta demanda (ex: Black Friday, campanhas de vacinação etc.).

Impacto no Custo:

Redução significativa nos gastos com servidores físicos e energia elétrica.

Eliminação de contratos longos com data centers locais.

2. Amazon S3 (Simple Storage Service)
Uso Sugerido: Armazenamento de documentos, notas fiscais, relatórios, imagens de produtos e backups.

Vantagens:

Armazenamento ilimitado com custo extremamente baixo.

Mecanismo de arquivamento com camadas inteligentes (ex: S3 Glacier para dados acessados raramente).

Alta durabilidade (99,999999999%) e disponibilidade.

Impacto no Custo:

Redução dos custos com discos rígidos, servidores de backup e manutenção.

A empresa só paga pelo que consome e pode automatizar a limpeza de arquivos antigos.

3. Amazon RDS (Relational Database Service)
Uso Sugerido: Bancos de dados para sistemas de vendas, CRM, controle de estoque e relatórios.

Vantagens:

Gerenciamento automático de backups, atualizações e failover.

Suporte a múltiplos mecanismos (MySQL, PostgreSQL, SQL Server etc.).

Escalabilidade vertical e horizontal conforme a demanda.

Impacto no Custo:

Menos necessidade de DBAs dedicados para manutenção rotineira.

Redução no tempo de indisponibilidade e custos com licenças.
